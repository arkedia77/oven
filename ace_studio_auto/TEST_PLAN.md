# ACE Studio GUI 자동화 — 테스트 플랜

## 개요
AppleScript + cliclick 조합으로 ACE Studio 데스크탑 앱(Qt 기반) 전 기능 자동화.
API/CLI 없으므로 GUI 제어가 유일한 방법.

## 모듈 구조

```
ace_studio_auto/
├── modules/
│   ├── core.sh          # 공통: 앱 활성화, 윈도우 위치, 대기, 좌표 계산
│   ├── import_midi.sh   # MIDI 가져오기
│   ├── instrument.sh    # AI 악기 트랙 생성/선택
│   ├── vocal.sh         # AI 보컬 트랙 생성/가사 입력
│   ├── export_audio.sh  # WAV/MP3 내보내기
│   ├── project.sh       # 프로젝트 새로 만들기/저장/열기/닫기
│   └── batch.sh         # 배치 오케스트레이터 (MIDI × 악기 조합)
├── tests/
│   ├── test_core.sh         # core 함수 단위 테스트
│   ├── test_import_midi.sh  # MIDI 가져오기 테스트
│   ├── test_instrument.sh   # 악기 선택 테스트
│   ├── test_vocal.sh        # 보컬 생성 테스트
│   ├── test_export.sh       # 내보내기 테스트
│   └── test_e2e.sh          # 전체 파이프라인 E2E 테스트
├── coords/
│   └── coords.json      # 캡처된 UI 좌표 (해상도별)
└── TEST_PLAN.md          # 이 파일
```

**핵심 발견:**

- 기본 저장 경로: ~/ACE_Studio/project/temp_workspace/working_document/
- **MP3 내보내기 (2026-04-26):** 형식 드롭다운에서 .MP3 선택 → 723KB, MPEG Layer III, 192kbps, 44.1kHz 스테레오
- **MIDI 내보내기 (2026-04-26):** 파일 → MIDI 내보내기 (AppleScript 메뉴 접근) → Standard MIDI format 1, 4 tracks, 480 ticks/beat
- Cmd+Shift+E는 MIDI 내보내기가 아님 (작동 안 함). macOS 메뉴바 "파일 → MIDI 내보내기" 사용 필수

## 기술 제약
- macOS 전용 (AppleScript + cliclick)
- ACE Studio가 foreground 필수 (화면 점유)
- Qt 커스텀 위젯은 AppleScript click 불가 → cliclick 필수
- 좌표 기반 → 해상도/윈도우 크기 변경 시 재캡처 필요
- 렌더링은 클라우드 기반 → 네트워크 지연 고려
- macOS 메뉴바(파일/편집/보기): 프로젝트에 콘텐츠 있을 때만 활성화
- 파일 다이얼로그 Cmd+Shift+G: keystroke 입력은 자동완성 방해 → pbcopy+paste 사용 필수
- Qt 컨텍스트 메뉴 서브메뉴(AI 도구 등): hover 타이밍 민감, 불안정
- 다이얼로그 버튼 클릭: cliclick 좌표보다 AppleScript 접근성 API가 안정적

## 필수 환경
- `brew install cliclick`
- 시스템 설정 → 개인정보 → 접근성 → Terminal 허용
- 시스템 설정 → 개인정보 → 전체 디스크 접근 → ACE Studio 허용
- ACE Studio 구독 활성화
